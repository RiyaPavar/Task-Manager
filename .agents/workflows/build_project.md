# Build Project Workflow

This workflow details the steps required to install dependencies and build the TeamSync project.

## Steps

1. **Install Dependencies**
   Run the following command to install all necessary npm packages:
   ```bash
   npm install
   ```

2. **Type Check (Optional)**
   Run the following command to verify TypeScript types:
   ```bash
   npm run typecheck
   ```

3. **Build for Production**
   Run the following command to create an optimized production build:
   ```bash
   npm run build
   ```
