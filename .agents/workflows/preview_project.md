# Preview Project Workflow

This workflow details the steps to start the development server and preview the TeamSync project.

## Steps

1. **Start Development Server**
   Run the following command to start the Next.js development server with Turbopack on port 9002:
   ```bash
   npm run dev
   ```

2. **Access the Preview**
   Once the server is ready, open your browser and navigate to:
   [http://localhost:9002](http://localhost:9002)

3. **Verify Functionality**
   - Ensure the login page renders.
   - Check the console for any errors.
   - Verify that AI features (Genkit) are working if an API key is provided in `.env`.
